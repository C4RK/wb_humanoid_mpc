# WEMT 无标记板手臂绑带支架

这个版本用于纯实机验证，不安装 ArUco/AprilTag。它固定 `23 × 13 × 70 mm` WEMT 接收器，
使用两条独立的 `25 mm` 魔术绑带，适用于大臂和前臂。

## 文件

- `wmet_receiver_fit_coupon.step/.stl`：打印完整件之前使用的 20 mm 长试装件；
- `wmet_receiver_strap_mount.step/.stl`：完整无标记板绑带支架；
- `parameters.json`：设计尺寸和打印参数；
- 参数化源文件：`scripts/generate_wmet_strap_mount.py`。

STEP 可以导入 SolidWorks/FreeCAD；STL 可以直接送入切片软件。

## 主要尺寸

- 支架底座：`68 × 84 × 2.6 mm`；
- 打印件总高度：约 `23.6 mm`；
- 加 3 mm EVA 后未压缩总高度：约 `26.6 mm`；
- 绑带槽：两组，每组适配 `25 mm` 宽绑带；
- 接收器：沿 70 mm 长轴从远端滑入；
- 防脱销孔：`2.1 mm`，使用约 34–36 mm 长的 `1.75 mm` 打印耗材。

## 打印顺序

1. 先用 PLA 打印 `wmet_receiver_fit_coupon.stl`；
2. 分别试装大臂和前臂接收器；
3. 两只接收器都能平稳滑入且没有明显晃动后，再打印两件完整支架；
4. 正式件推荐 PETG，层高 0.20 mm、至少 3 层外壁、30–40% 填充；
5. 让平整的外侧底面贴热床打印，正常不需要支撑。

试装件过紧或过松时，使用脚本的 `--side-clearance` 与
`--thickness-clearance` 调整，不要整体缩放 STL。

## 接收器安装

1. 让接收器带圆点开关的 `23 × 70 mm` 面朝支架底板；
2. 充电口一端从支架 `-Y` 远端滑入；
3. 推到 `+Y` 近端挡块；
4. 从远端横向穿入一段约 34–36 mm 长的 `1.75 mm` 打印耗材作为保险销；
5. 保险销位于接收器端面外侧，不穿过接收器或充电口；
6. 取出接收器时，先拔保险销，再从远端滑出。

不要使用磁铁、金属螺钉或金属保险销。

## EVA 与绑带

在身体侧两条高支撑轨顶部各粘一条约 3 mm 厚 EVA 防滑泡棉。两条支撑轨紧邻接收器滑槽，
用于适应手臂的弧形横截面；皮肤应接触泡棉，不直接接触接收器。

支架有近端和远端两组绑带槽：

```text
肩/肘方向（+Y，近端）
        近端绑带
   ┌────────────────┐
   │   接收器滑槽   │
   │                │
   │   接收器滑槽   │
   └────────────────┘
        远端绑带
肘/手腕方向（-Y，滑入口）
```

每条绑带从一侧槽固定，绕过手臂背面，再穿过同一高度的另一侧槽并折回粘紧。两条绑带必须
独立使用；不要只使用中间一条绑带。收紧到支架不旋转即可，不要导致手臂麻木、发白或影响
血液循环。

## 佩戴方向

支架近端有凸起箭头：

- 大臂：箭头朝肩膀，滑入口/充电口端朝肘部；
- 前臂：箭头朝肘部，滑入口/充电口端朝手腕。

实机验证不需要视觉标记，因此支架可安装在更稳定、舒适的位置；但接收器重新佩戴或旋转后，
必须重新完成当次 EM 标定。正式动作前再次确认两条绑带、EVA和保险销都没有松动。
