# 2026-10-23 G1 左臂逐级扩大范围测试

## 目的

在五关节小范围跟随已经通过的基础上，保持命令限速为 5°/s，逐级扩大相对于实机接管
姿态的安全包络，检查组合动作、方向、限幅、跟踪误差、机身稳定性和目标流连续性。

## 测试链路

双 WMET 接收器 → `dual_retargeting_node` → UDP 15000 →
`g1_arm_sdk_bridge.py` → `rt/arm_sdk` → G1。机器人处于 FSM 500；安全桥使用
`--relative-to-start`，五个左臂关节全部启用，最大命令速度 5°/s，最大允许跟踪误差 5°。

原始 CSV 位于仓库根目录 `calibration_logs/`。完整数值见
[tracking_metrics.csv](tracking_metrics.csv)，终端记录见
[range_tests.txt](terminal_transcripts/range_tests.txt)，校验值见
[raw_tracking_sha256.txt](raw_tracking_sha256.txt)。

## 运行结果

| 测试 | 安全包络 P/R/Y/E/W | 状态 | 时长与帧数 |
|---|---|---|---|
| 第一档 | 20/20/15/30/20° | 完整运行并释放 | 89.98 s，4500 帧 |
| 第二档 | 25/20/15/35/25° | 完整运行并释放 | 99.98 s，5000 帧 |
| 第三档首次 | 30/25/15/45/30° | 目标流陈旧 0.500 s，安全停止并释放 | 16.36 s，819 帧 |
| 第三档重试 | 30/25/15/45/30° | 完整运行并释放 | 119.98 s，6000 帧 |

第三档首次停止属于目标流连续性保护触发，不是关节超限、跟踪误差、机身速度或倾斜触发。
重试后相同幅度配置完整运行 120 秒。

## 跟踪误差

以下为命令角与编码器角的 RMSE / 最大绝对误差，单位为度。

| 测试 | pitch | roll | yaw | elbow | wrist |
|---|---:|---:|---:|---:|---:|
| 第一档 | 0.92 / 2.91 | 1.65 / 3.63 | 0.49 / 1.41 | 0.48 / 1.15 | 0.28 / 0.95 |
| 第二档 | 1.05 / 3.24 | 1.84 / 3.32 | 0.52 / 1.41 | 0.62 / 2.58 | 0.34 / 0.96 |
| 第三档重试 | 1.01 / 3.37 | 2.12 / 3.92 | 0.51 / 1.56 | 0.89 / 4.83 | 0.29 / 0.95 |

三个完整测试的最大误差均低于 5° 停止阈值。roll 的持续误差最大；第三档 elbow 的瞬时
最大误差为 4.83°，已经接近 5° 阈值，但其 RMSE 为 0.89°，P95 为 1.05°，属于短时动态
跟踪滞后。

## 幅度与稳定性

- 第一档五个命令均到达所设安全边界；实际最大相对幅度约为
  pitch 19.8°、roll 17.9°、yaw 14.9°、elbow 29.2°、wrist 19.9°。
- 第二档五个命令均到达安全边界；实际最大相对幅度约为
  pitch 25.9°、roll 18.4°、yaw 15.1°、elbow 34.9°、wrist 24.9°。
- 第三档重试的 pitch、roll、yaw 和 elbow 命令分别到达 30°、25°、15° 和 45°；实际
  最大相对幅度约为 32.8°、22.4°、14.9° 和 44.8°。wrist 命令最大相对幅度只有
  18.4°，因此本轮没有验证 wrist 30°。
- 完整测试中 IMU 最大倾角为 2.13°，保持关节和身体最大速度为 0.201 rad/s，均低于
  当前安全阈值。

安全桥多次把人体映射产生的更大 `applied` 目标限制在分关节安全包络内。终端中出现较大
的 `source` 或 `applied` 数字不代表机器人收到了该角度；需要以 `desired` 和 `actual`
两列判断实际命令与执行结果。

## 目标流连续性

三个完整测试的目标年龄中位数为 0.52–0.54 ms，P95 为 1.17–1.24 ms，但每次都出现一次
约 400.6–400.8 ms 的短暂停顿。第三档首次运行的停顿达到 0.500 s，触发安全停止。第三档
重试仍出现 400.6 ms 峰值，但未达到 500 ms 停止阈值。正式论文试验前仍需定位这一周期性
数据停顿。

## 结论与限制

本次测试支持以下结论：五关节在 5°/s 下能够在更大安全包络内同时工作；分关节限幅、
跟踪误差保护、目标超时停止和缓慢释放均按预期工作；控制精度满足当前 5° 阈值。

这组测试还不能记为完整功能序列最终通过。第二档结束前 roll、yaw 等关节仍偏离基准；第三
档重试结束前 elbow 仍比基准弯曲约 44°，说明动作时间表没有在截止前完成回中。此外，最大
档 wrist 30°尚未覆盖。下一次只需做一次短补测：覆盖 wrist 大幅旋转，并预留足够时间让
所有关节返回基准；不需要重做前三档全部范围测试。完成该补测并检查 CSV 后，再进入
5→8→10°/s 的速度递增测试。
