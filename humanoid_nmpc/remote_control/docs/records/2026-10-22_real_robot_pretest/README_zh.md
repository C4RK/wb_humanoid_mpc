# 2026-10-22 G1 左臂实时重定向预实验记录

## 1. 记录性质

这是为后续论文和正式实验保留的**预实验记录**。它记录当天真实执行过的测试，包括一次中止试验；不把未执行的计划项目写成已经完成。

本记录可以用于：

- 证明 `rt/arm_sdk` 安全桥能够驱动 G1 左臂，并记录目标角与编码器角；
- 选择正式实验的幅值、速度和安全阈值；
- 检查数据文件、时间戳、通信状态和停止逻辑；
- 为正式实验表格和绘图代码提供样例数据。

本记录不能单独证明人体到机器人的绝对重定向精度。CSV 中的误差是安全桥输出的关节命令与机器人编码器角之间的误差；人体肢段方向的精度仍需双相机和视觉标记等独立真值。

## 2. 实验环境和固定参数

- 日期：2026-10-22；文件名时间为 UTC，德国现场时间为 CEST（UTC+2）。
- 机器人：Unitree G1，实机运控状态为 FSM 500。
- 网络接口：`enx6c1ff701509c`；机器人地址：`192.168.123.161`。
- 控制链：双 WMET 接收器 → `dual_retargeting_node` → UDP 15000 → `g1_arm_sdk_bridge.py` → `rt/arm_sdk`。
- 映射：`--relative-to-start`；接管结束时将当前人体姿态对齐到当时的机器人姿态。
- 通用限制：`--max-body-speed-rad-s 0.30`、`--max-tracking-error-deg 5`、`--target-timeout 0.50`。
- 除快速肘部测试使用 `5 deg/s` 外，其余测试使用 `3 deg/s`。
- 每轮结束均看到 Arm SDK 权重平滑回到零。
- 分析时使用 CSV 的 `command_*` 作为安全限速后的目标，使用 `actual_left_*` 作为编码器实测值。

代码基准提交为 `79a92391f3b53edcc48bbe093df1d34a24c56624`，但实验时工作区有未提交修改，因此不能只靠 Git 提交复现实验。实际关键文件的 SHA-256 保存在 [software_sha256.txt](software_sha256.txt)。

## 6. 通信和停止事件

完整试验中，UDP 目标年龄的中位数约为 0.6–1.3 ms，绝大多数帧很新；但多轮出现少量 361–404 ms 的尖峰。完整试验共有 280/56,750 帧的目标年龄超过 250 ms，约 0.49%。这些尖峰低于当天使用的 500 ms 停止阈值，所以没有触发停止。

`T131335Z` 出现超过 500 ms 的持续空档，程序按设计执行：停止跟踪、平滑释放 Arm SDK 权重并保存 CSV。这个结果说明失联保护有效，同时也说明正式论文实验前仍需解决目标流中偶发的长空档。按照论文评估计划中“最长中断小于 250 ms”的建议目标，当天通信新鲜度尚不能判为正式通过。

## 9. 预实验结论

1. 实机命令链路已经能够安全接管、跟踪并释放左臂；32 轮完整试验均未触发 5°跟踪误差停止。
2. 肘、腕和 yaw 的控制跟踪误差较小；pitch 可接受；roll 在负载下误差最大，是正式实验重点观察轴。
3. 单关节扩大幅值和低幅值多关节组合均已获得可用预实验数据。
4. 目标流存在稀疏的 0.36–0.40 s 空档，并有一次 0.520 s 空档触发安全停止；正式采集前需诊断并改善。
5. 这些结果支持继续设计正式试验，但不能替代重新佩戴重复实验、视觉真值和预先固定的统计方案。
