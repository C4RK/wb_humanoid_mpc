# 毕设定量评价与演示方案

本方案回答三个问题：人体动作有没有被正确估计、机器人有没有正确跟踪目标、机器人在跟随时
是否安全稳定。三者必须分别评价。MuJoCo 视频适合说明系统行为，但不能代替误差数据。

## 1. 论文最终要证明什么

建议把论文结论限制为以下四项：

1. 每次重新佩戴后，系统能通过当次标定恢复人体左臂的方向和肘角；
2. 双接收器重定向能实时产生连续、可重复的 G1 左臂目标；
3. 安全层能阻止左臂进入躯干，并在离开危险区后连续释放；
4. 慢速手臂动作在 MuJoCo 和吊架保护下的 G1 上可以稳定执行。

如果没有独立的人体姿态测量，只能证明“一致性和重复性”，不能把标定残差直接称为绝对
精度。当前 `forearm residual` 描述参考动作与标定模型的一致程度，并不是用独立仪器测得的
人体真值误差。

## 2. 六组核心指标

| 层级 | 指标 | 单位 | 需要的数据 | 回答的问题 |
|---|---|---:|---|---|
| 传感器/标定 | 静止位置和姿态标准差、参考姿势重复误差 | mm、deg | 标定终端和 reference NPZ | 数据是否稳定、重新摆姿势是否一致 |
| 人体动作估计 | 大臂方向误差、前臂方向误差、肘角误差 | deg | EM 结果和独立真值 | 人体动作是否估计准确 |
| 重定向 | 机器人 FK 后的肢段方向/归一化手位误差、路径终点差 | deg、% 或 cm | 人体真值、目标关节角、G1 模型 | 跨人体和机器人形态后是否保留动作语义 |
| 实时性 | 更新率、帧丢失率、最长中断、延迟 | Hz、%、ms | 时间戳和完整日志 | 是否适合实时遥操作 |
| 真机控制 | 目标角与编码器角的 RMSE、P95、最大误差 | deg | `g1_arm_tracking_*.csv` | 机器人是否真正执行了目标 |
| 安全与平衡 | 最小躯干间隙、保护介入率、基座倾角、是否踏步/跌倒 | mm、%、deg | retargeting NPZ、MPC/IMU/视频 | 系统是否安全稳定 |

方向误差使用两个单位向量之间的夹角：

```text
e_dir = acos(clip(u_estimate · u_ground_truth, -1, 1))
```

肘角误差为：

```text
e_elbow = abs(theta_estimate - theta_ground_truth)
```

人体与 G1 的臂长不同，因此不要直接比较人体手坐标和机器人手坐标。可以比较大臂/前臂
单位方向，或比较相对于肩部并按臂长归一化的手位置：

```text
e_hand = norm((p_human_hand-p_human_shoulder)/L_human
              - (p_robot_hand-p_robot_shoulder)/L_robot)
```

每项误差至少报告 `RMSE、median、P95、max`。跨标定重复实验再报告各次试验结果的
`mean ± SD` 或 `median [IQR]`。连续 5000 帧不能当成 5000 次独立实验；统计单位应是
一次动作、一次重新佩戴标定或一名参与者。

## 3. 怎样取得“人体真值”

按可信度排序：

1. **光学运动捕捉**：最理想，可以直接给大臂、前臂姿态作独立参考；
2. **两台标定相机加刚性视觉标记**：在两个接收器附近固定 ArUco/AprilTag 标记，正面和
   侧面同步拍摄并重建方向。这是本项目成本较低、论文上较容易说明的方法；
3. **数字倾角仪/机械角度基准**：适合验证前举、侧举、伸肘等静态平面动作，不能完整
   覆盖任意 3D 运动；
4. **人工摆出的 DOWN/FORWARD/SIDEWAYS**：只能用作参考姿势一致性检查，不能称为
   高精度地面真值。

普通单目人体姿态网络可以作辅助可视化，但不建议单独作为本系统的精度真值。若实验室没有
动捕，优先采用方案 2；不需要用卷尺测量人的臂长。

两台手机、ChArUco 标定板和人体 ArUco 标记的现场操作见
[`two_phone_visual_validation_protocol_zh.md`](two_phone_visual_validation_protocol_zh.md)。

## 4. 最小可完成的实验矩阵

### 4.1 每次佩戴内的准确性和重复性

每次拆下设备后都重新安装并重新标定，只使用当次成功标定。完成：

- `DOWN、FORWARD、SIDEWAYS、STRAIGHT_DOWN、STRAIGHT_FORWARD`，每个姿势重新构建
  3 次，每次保持 5 秒；
- 屈伸肘 3 个往返；
- 直臂前举 3 个往返；
- 直臂侧举 3 个往返；
- 路径 1“下垂→侧举”和路径 2“下垂→前举→侧举”各 3 次；
- 胸前接近躯干并返回 3 次，用来评价碰撞层。

至少完成 **10 次独立重新佩戴与标定**。这组数据最能支撑题目中的 “Adaptive”：算法应在
安装角度每次略有变化时，通过当次标定恢复相近的输出。若时间允许，再加入 3–5 名参与者；
涉及其他参与者前先确认学校的伦理审批和知情同意要求。

### 4.2 对照/消融实验

优先级从高到低：

1. 单接收器与双接收器使用相同动作，比较前臂方向和肘角误差；
2. 当次标定修正前后，比较参考姿势和独立测试姿势误差；
3. MuJoCo 中关闭/开启碰撞层，比较最小间隙和穿模帧数；
4. 同一段回放在手臂静止与手臂运动时，比较基座姿态和下肢补偿。

关闭碰撞层的实验只在 MuJoCo 中做。若没有“关闭 MPC”的可靠仿真条件，不要声称 MPC
比其他控制器提高了多少，只报告在 MPC 下的稳定性和全身补偿。

### 4.3 仿真与真机

仿真使用同一个保存的重定向轨迹回放，以排除每次人体动作不同造成的影响。记录：

- 五个手臂目标角；
- 基座 roll/pitch、下肢和腰关节变化；
- 双脚是否持续接触、是否滑移或踏步；
- 碰撞原始间隙、安全间隙、介入帧比例和修正角；
- MPC 周期超时比例和最大超时。

当前 MPC observation logger 中接触力相关数据尚未确认有效，代码也有 `Add contact forces
later` 标记。在修正和验证前，不把其 `F/M` 列用于论文足底力结论。

真机先只做固定 5° 小动作，再做慢速小范围屈伸肘。`g1_arm_sdk_bridge.py` 会在释放控制后
保存 `g1_arm_tracking_*.csv`，其中包括：

- ROS 输入目标和安全限速后的实际命令；
- G1 的 23 个关节编码器角和速度；
- IMU roll/pitch/yaw；
- UDP 序号、目标年龄和传输延迟。

这份 CSV 用于计算五个左臂关节的目标—实测 RMSE/P95/max，以及机身倾角和下肢补偿。
UDP 延迟只覆盖 ROS 发送节点到主机桥接循环；目标到机器人响应的动态滞后可用目标和编码器
时间序列的互相关估计。完整的人体动作到机器人响应延迟还包含 WEMT 采集时间，需要同步的
视觉事件、硬件时间戳或其他外部基准才能严格测量。

## 5. 预先设定的工程验收线

这些是本项目的工程目标，不是机器人领域通用标准。正式采集前写入实验方案，采集后不要为
了让结果通过而改阈值：

| 项目 | 建议目标 |
|---|---:|
| 静止时 pitch/roll/elbow 标准差 | `< 2°` |
| 静止时 yaw/wrist 标准差 | `< 3°` |
| 同一姿势跨 3 次的肩部终点差 | `< 5°` |
| 同一姿势跨 3 次的肘部终点差 | `< 8°` |
| 有独立真值时的肢段方向 RMSE | 目标 `< 10°`，同时报告 P95 |
| 两条路径到同一侧举终点的 pitch/roll 差 | `< 5°` |
| 有效输出频率 | `45–55 Hz` |
| 丢帧比例 | `< 1%`，且最长中断 `< 250 ms` |
| 慢速真机左臂关节跟踪 RMSE | 目标 `< 3°`，最大误差 `< 8°` |
| 碰撞层安全间隙 | 所有有效帧 `>= 25 mm` |
| 碰撞或关节限位违规 | `0` 次 |
| 站立试验基座 roll/pitch | 先以静止基线为准；建议峰值 `< 3°` |
| 踏步、脚滑、跌倒、急停触发 | `0` 次正常试验 |

当前约 `10–14°` 的前臂固定残差可以支持定性演示，但不能描述为高精度。论文应同时展示
误差数值、稳定性和局限，而不是只给“通过/失败”。

## 6. 每次实验的文件和元数据

每次实验建立一个目录，例如：

```text
experiment_data/
  S01_install01_2026-10-18/
    metadata.yaml
    wmet_dual_calibration.yaml
    dual_reference_....npz
    dual_retargeting_....npz
    mpc_observation_....csv
    g1_arm_tracking_....csv
    front_video.mp4
    side_video.mp4
```

`metadata.yaml` 至少写：参与者匿名编号、安装编号、时间、代码 Git commit、接收器 IP 与身体
位置、动作顺序、动作起止时间、是否仿真/真机、MPC 与安全层参数、附近金属和异常说明。
失败试验也要保留并标明失败原因，不能只选择最好的一次。

## 7. 论文中建议给出的图表

1. 系统框图：EM 接收器→标定→重定向→碰撞层→MPC/arm SDK→G1；
2. 10 次重新佩戴的标定残差箱线图；
3. 五个姿势的大臂方向、前臂方向和肘角误差箱线图；
4. 单接收器和双接收器误差对照表；
5. 一次动态动作的目标角与真机编码器角时间曲线；
6. 更新周期/传输延迟的直方图或累积分布；
7. 碰撞层的原始间隙与安全间隙曲线；
8. 手臂运动期间的基座 roll/pitch 和下肢关节变化；
9. 仿真与真机相同动作的并排关键帧。

## 8. 最终演示内容

演示只需清楚回答“跟得上、不会撞、站得住”：

1. 展示本次标定通过页面和实时更新率；
2. 人和 MuJoCo/G1 分屏，缓慢完成屈伸肘、弯肘前举、直臂前举、侧举和斜向举；
3. 手臂缓慢靠近胸前，实时显示原始间隙降到阈值、安全间隙保持 25 mm；
4. 屏幕叠加五个目标/实测关节角、基座 roll/pitch、延迟和丢帧状态；
5. 结束后显示本次 CSV/NPZ 路径和简短统计。

已知不可观测区要主动说明：肘接近完全伸直时，肩部轴向旋转和前臂旋转不能由两个肢段方向
唯一分开，当前程序会保持稳定值。最终演示不把直臂主动转掌作为主要能力展示。

## 9. 下一步执行顺序

1. 先确定独立人体真值方案，推荐双相机加刚性视觉标记；
2. 固定动作脚本和上述验收线，不再边采集边改变动作定义；
3. 做 2 次预实验，检查所有日志能够按时间对齐；
4. 完成 10 次重新佩戴实验；
5. 用一条选定的有效轨迹完成 MuJoCo 回放和 MPC 数据采集；
6. 真机从固定 5°动作开始，再逐步进入慢速在线跟随；
7. 最后统一生成表格和图，不从终端每秒打印值手工抄数据。

## 10. 方法参考

- [Calibration and characterization of electromagnetic position and orientation trackers](https://pmc.ncbi.nlm.nih.gov/articles/PMC12726960/)：说明 EM 跟踪精度需要借助已知位置/姿态真值表征，并强调测试运动维度应覆盖实际使用的自由度；
- [Skinned Motion Retargeting With Residual Perception of Motion Semantics & Geometry](https://openaccess.thecvf.com/content/CVPR2023/html/Zhang_Skinned_Motion_Retargeting_With_Residual_Perception_of_Motion_Semantics__CVPR_2023_paper.html)：使用按角色高度归一化的关节位置误差，并单独评价穿透和自接触；
- [Unsupervised Neural Motion Retargeting for Humanoid Teleoperation](https://arxiv.org/abs/2406.00727)：在人机形态不同的遥操作中使用末端位置误差评价重定向性能。
