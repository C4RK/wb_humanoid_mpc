# 双接收器手臂重定向：标准验证流程

这份流程用于比较不同标定、算法版本和佩戴方式。每次都按相同顺序、相同速度和相同保持
时间完成动作。`dual_retargeting_node` 会保存全频率 NPZ，因此不需要从终端每秒一条的打印
反推动作。

如果发射器或任一接收器被摘下、移动或重新粘贴，必须重新标定。本次标定生成的 YAML 只
适用于本次安装。

## 1. 五个输出角和参考零位

输出顺序是：

1. `pitch`：大臂前举/后摆分量；
2. `roll`：大臂向左侧抬起分量；
3. `yaw`：大臂绕自身轴内旋/外旋；
4. `elbow`：肘部从弯曲约 90° 到伸直；
5. `wrist`：前臂旋前/旋后。

重定向零位使用标定中的 `DOWN`：左大臂竖直下垂，肘弯约 90°，前臂水平向前，手掌
朝右/身体内侧，拇指向上。这个姿势下五个输出应接近 `0°`。

机器人肘角采用项目内部约定：人体肘弯约 90° 对应 `elbow≈0°`，人体肘伸直对应
`elbow≈+90°`。

## 2. 仿真启动

当前安装没有变化时，不需要重新标定。依次启动：

```bash
# 终端 1
source /wb_humanoid_mpc_ws/install/setup.bash
ros2 run remote_control dual_em_tracker_node

# 终端 2
source /wb_humanoid_mpc_ws/install/setup.bash
ros2 launch g1_centroidal_mpc mujoco_sim.launch.py

# 终端 3：MuJoCo 专用发布
source /wb_humanoid_mpc_ws/install/setup.bash
ros2 run remote_control dual_retargeting_node --ros-args \
  -p publish_joint_targets:=true \
  -p simulation_only:=true
```

启动终端 3 前先摆好 `DOWN`。等 MuJoCo 中机器人稳定站立后，再缓慢开始动作。

## 3. 核心测试动作

每个动作在 3–5 秒内缓慢完成，到达终点后保持 5 秒，再用 3–5 秒返回。不要快速甩动。
除“前臂旋转”外，手腕始终保持中立；除“躯干相对运动”外，躯干始终保持不动。

### A. 起点静止

保持 `DOWN` 5 秒。观察：

- 五个角是否接近零；
- 静止时是否持续漂移或跳变；
- 是否出现 `Upper position radius error` 或数据看门狗警告。

### B. 单独伸肘

保持大臂竖直下垂、前臂指向正前方和手腕中立，只把肘从约 90° 缓慢伸直到直臂，保持
5 秒，再弯回 `DOWN`。

预期：`elbow` 从约 `0°` 增加到约 `+90°` 后返回；`pitch/roll` 基本不变。接近完全
伸直时，`yaw/wrist` 在数学上不可观测，程序应保持最后稳定值，不应突然跳几十度。

### C. 单独旋转前臂

保持 `DOWN` 的大臂位置、肘角和前臂指向不变。让手、手腕和前臂作为一个整体：

1. 从拇指向上开始；
2. 缓慢向一个方向转约 45°，保持 3 秒；
3. 回到拇指向上，保持 3 秒；
4. 向相反方向转约 45°，保持 3 秒；
5. 回到拇指向上。

预期：主要变化是 `wrist`；`pitch/roll/elbow` 基本不变。不要转到人体解剖极限。

### D. 弯肘前举

从 `DOWN` 出发，保持肘弯约 90°，把整条 L 形手臂向前抬：大臂最终水平向前，前臂
竖直向上，不主动转掌。这个终点就是标定中的 `FORWARD`。

预期终点大约为：`pitch=-90°`、`roll=0°`、`yaw=0°`、`elbow=0°`、`wrist=0°`。
这里主要检查前举方向和前臂整体方向偏差。

### E. 直臂前举

先回到 `DOWN`，伸直肘并让整条手臂下垂，然后把直臂向前抬到肩高。手臂始终指向
正前方，不要跨过胸前或向外偏；手掌朝右/内侧，拇指向上。

预期终点大约为：`pitch=-90°`、`roll=0°`、`elbow=+90°`。直臂时不单独评价
`yaw/wrist`，因为两者的可观测性降低。

### F. 直臂侧举

从整条手臂自然下垂且肘伸直开始，拇指始终朝前，向左侧抬起到肩高。终点为整条手臂
水平向左、手掌向下、拇指向前。

预期终点大约为：`pitch=0°`、`roll=+90°`、`elbow=+90°`。侧向抬起约超过 60°后，
终端会提示采用 canonical pitch；这是侧向奇异区保护正常生效。

### G. 肩部轴向旋转

回到 `DOWN`。保持大臂竖直、肘弯约 90°、前臂水平。通过肩部内旋/外旋，让整根前臂
在水平面内向身体内侧和外侧各摆约 30°。手、前臂和肘的平面作为整体运动，不要只转
手掌。

预期：主要变化是 `yaw`；`pitch/roll/elbow` 基本不变，`wrist` 不应出现同幅变化。

## 4. 路径一致性测试

这个测试专门检查以前出现过的“从前平举转到侧平举时，机器人手臂比直接侧平举更高”。
两条路径必须到达完全相同的最终人体姿势。

### 路径 1

1. 直臂下垂，保持 3 秒；
2. 直接做直臂左侧平举；
3. 在标准 `SIDEWAYS` 姿势保持 5 秒；
4. 回到直臂下垂。

### 路径 2

1. 直臂下垂，保持 3 秒；
2. 直臂前平举，保持 3 秒；
3. 保持手臂水平，通过水平圆弧转到标准 `SIDEWAYS`；
4. 保持 5 秒；
5. 回到直臂下垂。

两条路径各做两次。最终侧平举时应满足：

- `pitch` 都收敛到约 `0°`；
- `roll` 都接近 `+90°`；
- MuJoCo 中左手高度差尽量小于 5 cm；
- 不应保留进入侧向区域之前的 `pitch`；
- 从任一路径返回下垂后，关节角都应回到相近数值。

## 5. 组合方向和重复性

完成核心动作后再做以下动作：

1. **前左斜向直臂伸出**：手臂在肩高，方向位于正前方与正左方中间，保持 5 秒；
2. **前举—下垂循环**：用约 6 秒完成一次往返，连续 3 次；
3. **侧举—下垂循环**：用约 6 秒完成一次往返，连续 3 次；
4. **重复终点**：分别重新构建 `DOWN`、`FORWARD`、`SIDEWAYS`，每个姿势重复 3 次，
   每次都先离开姿势再重新进入。

斜向动作检查 `pitch+roll` 的组合映射。循环检查滤波延迟、速度限制和是否积累漂移。
重复终点用于区分固定系统偏差和佩戴/动作重复误差。

## 6. 躯干相对运动测试

发射器固定在躯干上，因此系统输出描述手臂相对躯干的动作。保持 `DOWN` 不变，带着
发射器和整条手臂一起缓慢：

1. 身体向左、向右各转约 15°；
2. 身体轻微前倾并回正；
3. 全程保持肩、肘、腕相对躯干不变。

理想情况下五个输出变化很小。如果出现明显变化或半径错误，原因更可能是发射器固定、
环境金属干扰或人体动作没有保持刚性，而不是 G1 关节映射。

## 7. 侧上举边界测试

侧向分支支持从水平面下方连续通过 90°，测试顺序为
`70° → 90° → 110° → 90° → 70°`。机器人 `roll` 应连续通过 90°，`pitch` 在侧向
保护区保持接近 0°，不能从 90°折返或突然跳到接近 180°。

这项测试只在 MuJoCo 中进行。G1 当前左肩 roll 上限约为 129°，因此侧上举终点暂定
110°，不要继续向头顶方向抬到关节限位。

同样暂不测试快速挥臂、突然反向、人体关节极限和大幅躯干运动。这些动作应在慢动作的
几何精度、路径一致性和 MPC 稳定性通过后再加入。

## 8. 左臂—躯干碰撞保护测试

只在 MuJoCo 中测试，保持默认 `enable_torso_collision_filter:=true` 和 25 mm 间隙。
所有动作都用至少 5 秒缓慢完成：

1. 从 `DOWN` 开始，让左大臂逐渐贴近身体，再稍微向外移开，重复 3 次；
2. 肘保持伸直，直臂下垂时重复相同的内收—外展动作；
3. 大臂向前约 45°、肘弯约 90°，再缓慢向胸前内收并返回；
4. 做标准直臂前平举和直臂侧平举，确认安全姿态不会被明显改变。

接近躯干时，MuJoCo 中的手臂应停在躯干外侧，终端出现 `torso guard`。人体继续向内时，
机器人不能继续穿入躯干；人体向外返回后，保护应自动释放且不能产生关节跳变。标准侧平举
通常应保持 `collision_filter_active=false`。

结束后检查 NPZ：

- 所有有效帧的 `collision_safe_clearance_m` 不小于配置值（数值容差 0.1 mm）；
- `collision_filter_held` 应只在肩 roll 投影无法得到安全解时短暂出现；
- `commanded_joint_angles_rad` 与 `pre_collision_joint_angles_rad` 的差异应主要位于肩 roll；
- 保护进入和退出过程中，相邻命令不能出现明显不连续。

可额外做一次关闭保护的 MuJoCo 对照，以确认原本的碰撞确实被过滤器阻止：

```bash
ros2 run remote_control dual_retargeting_node --ros-args \
  -p publish_joint_targets:=true \
  -p simulation_only:=true \
  -p enable_torso_collision_filter:=false
```

关闭保护的对照一旦看到接触或穿入就立即停止，不做快速动作，也不连接实机。

## 9. 当前阶段的验收标准

可先使用以下工程门槛：

- 静止 5 秒：`pitch/roll/elbow` 标准差小于 2°，`yaw/wrist` 小于 3°；
- 同一姿势重复 3 次：肩部角差小于 5°，肘角差小于 8°，`yaw/wrist` 小于 10°；
- 单独动作对无关关节的串扰通常小于 8°；
- 两条侧平举路径的最终 `pitch/roll` 差小于 5°，MuJoCo 左手高度差小于 5 cm；
- 没有持续的半径错误、接收器失联或关节角几十度跳变；
- MuJoCo 中双脚保持接触，机器人不跌倒、不踏步，腿、髋和躯干只做小幅平衡补偿。

前臂当前存在约 10°量级的固定方向残差。固定偏差和静止噪声需要分开评价：稳定但有
偏差说明标定/模型仍需改进；同一姿势持续跳动说明采集、固定或滤波存在问题。

## 10. 每次测试需要保留的内容

测试结束后在重定向终端按 `Ctrl+C`，确认出现：

```text
Saved ... full-rate diagnostic frames to ...dual_retargeting_....npz
```

保留并报告：

1. 新生成的 NPZ 完整路径；
2. 是否严格按本流程完成，哪些动作遗漏或做错；
3. MuJoCo 中最明显的异常动作及其发生在第几项；
4. 测试期间所有半径错误、数据中断或 MPC 异常；
5. 如果方便，保留固定视角的视频，用于比较机器人末端高度和全身平衡反应。

## 11. 真机前的门槛

真机仍按以下顺序推进，并始终使用吊架和急停：

1. 只读底层状态，确认关节索引、符号、单位和更新率；
2. 不接电磁设备，重复单关节 5° 固定动作；
3. 五个手臂关节分别做小角度动作，验证速度限制、数据超时和急停；
4. 双脚固定站立，给 MPC 缓慢的固定手臂目标，观察踝、髋和腰的平衡补偿；
5. 接入电磁目标，先做静态姿势，再做上述慢速核心动作；
6. 仿真与真机结果一致后，再逐步增加范围和速度。

站立实验中，MPC 应主要通过小幅踝、髋、腰和接触力变化抵消手臂引起的质心与角动量
变化。当前任务不要求机器人跟随每次手臂动作踏步。
